# IMQF Master's Thesis: Spanish Motor-Insurance Portfolio

Data documentation for my master's thesis in the **International Master in Quantitative Finance (IMQF)**.

## Contents

| File | Description |
|---|---|
| `Descriptive of variables.xlsx` | Descriptive statistics for the variables used in the thesis |
| [`LITERATURE.md`](LITERATURE.md) | Annotated literature review: 17 sources on GLM versus machine-learning pricing, calibration, financial consequences, interpretability and fairness |

## Dataset

The thesis uses secondary data published by Priscila Espinosa, Josep Lledó and David Atance: anonymised motor-insurance policies from January 2022 to December 2024, with 354,140 records and 47 variables, including coverage-specific financial information.

- **Download the original dataset:** [Mendeley Data](https://data.mendeley.com/datasets/sw4jmdb2sm/1)
- **Accompanying article:** [Data in Brief](https://www.sciencedirect.com/science/article/pii/S235234092600435X)

**Citation:**

Espinosa, P., Lledó, J., & Atance, D. (2026). *A detailed dataset of motor insurance policies with coverage-specific financial information* [Dataset]. Mendeley Data, Version 1. https://doi.org/10.17632/sw4jmdb2sm.1
